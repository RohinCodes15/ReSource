# Congressional App Challenge submission checklist

This is a preparation checklist, not a statement that any item is complete or that current contest rules have been checked. Confirm dates, eligibility, format, and required materials against the student's official district challenge instructions.

## Product and demo

- [ ] Run `npm test`, `npm run typecheck`, `npm run lint`, `npm run db:validate`, and `npm run build`; record actual output and skipped checks.
- [ ] Rehearse the 3-minute script in [DEMO_GUIDE.md](DEMO_GUIDE.md); verify links, keyboard flow, reset, and viewport before recording.
- [ ] Decide whether judges will see the browser-only demo or a database-backed environment. Never imply the simulation persists.
- [ ] Test the authenticated transfer journey against a dedicated isolated PostgreSQL test database before presenting it as operational.
- [ ] Record the result of `npm run test:integration`; skipped integration tests do not count as passing.
- [ ] Confirm no secrets, personal data, real school records, or unapproved logos are included.
- [ ] Check captions/audio, readable text, keyboard-only navigation, and mobile framing if recording a video.

## Explanation and ownership

- [ ] Student can explain the data model, exact-type filters, scoring factors, allocation objective and limitations, and savings terminology.
- [ ] Student reviews AI-assisted code and documents what they personally designed, tested, changed, and learned.
- [ ] Label fictional organizations and metrics in every screenshot or recording.
- [ ] If educators provide feedback, describe who was invited in aggregate, methods and limitations; do not imply endorsement.

## Official submission

- [ ] Verify current official district deadline and entry instructions with a teacher/adult mentor.
- [ ] Prepare project description, source/code link if required, demo/video if required, and any required permissions.
- [ ] Proofread all claims; distinguish implemented, simulated, tested, unverified, and planned features.
- [ ] Submit with time to spare and retain a copy of the final materials and confirmation.
